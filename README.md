# 1C Solution Advisor

Веб-приложение для консультантов по продуктам 1С для подбора подходящих конфигураций под бизнес-клиента в Казахстане.

## Описание

Приложение проводит консультанта через пошаговую анкету о бизнесе клиента и автоматически формирует объяснимую рекомендацию по конфигурациям 1С с учетом особенностей казахстанского рынка.

## Поддерживаемые конфигурации

1. 1С:Бухгалтерия 8 для Казахстана
2. 1С:Зарплата и управление персоналом 8 для Казахстана
3. 1С:Розница 8 для Казахстана
4. 1С:Управление торговлей 8 для Казахстана
5. 1С:Управление нашей фирмой 8 для Казахстана
6. 1С:Комплексная автоматизация для Казахстана
7. 1С:ERP Управление предприятием 2 для Казахстана
8. 1С:Документооборот 8 КОРП для Казахстана

Для отраслевых решений (например, общепита) справочник отмечает необходимость отдельного подбора и проверки локализации.

## Архитектура

- src/types/ - типизированные модели данных
- src/data/ - данные конфигураций, вопросов, правил подбора
- src/engine/ - бизнес-логика алгоритма подбора
- src/components/ - React-компоненты
- src/pages/ - страницы приложения
- 	ests/ - автоматические тесты

## Принцип работы алгоритма

Алгоритм использует экспертную систему на основе правил:
- Каждый вопрос активирует правила, оценивающие пригодность конфигураций
- У каждой конфигурации есть баллы пригодности, причины выбора
- Система учитывает комбинации конфигураций (например, Розница + Бухгалтерия)
- При недостатке данных формирует предупреждение и список уточнений
- Оценка уверенности - внутренняя оценка алгоритма, не статистическая вероятность

## Особенности

- Работает полностью на клиенте (локальное состояние)
- Адаптивный дизайн
- Пошаговая анкета с динамическими вопросами
- Печатный отчёт
- Расширяемая архитектура для добавления конфигураций, вопросов и правил

## Ограничения

- Данные о конфигурациях основаны на общедоступной информации
- Для точной проверки совместимости, редакции и локализации необходима консультация с 1С
- Не сохраняет персональные данные клиентов
