# Changelog

All notable changes to this project are documented here.

## 0.2.0 - 2026-10-27

### Added
- Added a catalog page with plain-language descriptions of additional 1C solutions.
- Added direct links from missing-information warnings to the related questionnaire questions, with a button to recalculate and return to the result.
- Added questionnaire follow-ups for warehouse count, production complexity, and payroll complexity.

### Changed
- Aligned configuration names and catalog descriptions with the Kazakhstan product line.
- Revised recommendations to use actual questionnaire answers and show required configuration combinations together.
- Marked industry-specific catering software as requiring separate selection and localization checks instead of recommending it as a standard Kazakhstan configuration.
- Updated the README configuration list and the catering recommendation test.
